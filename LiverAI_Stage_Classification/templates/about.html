LiverAI — Machine Learning-Based Liver Cirrhosis Stage Classification

The application accepts structured clinical variables and uses a trained classification pipeline to return one of three dataset stage labels (Stage 1, Stage 2, or Stage 3), along with model class probabilities.

Problem statement

Clinical datasets can contain multiple laboratory measurements and categorical observations. This project demonstrates how a supervised machine learning workflow can prepare such inputs, train a multiclass classifier, expose predictions through a Flask application, and present evaluation results in a usable interface.

Project objectives

  • Prepare and validate a labelled dataset.
  • Train a repeatable preprocessing and Random Forest pipeline.
  • Classify inputs into the dataset's three stage labels.
  • Show class probabilities and held-out evaluation metrics.
  • Keep a local demo history and allow CSV export.

How the system works

01Input

Enter demographic, treatment, observation, and laboratory values.

02Preprocess

Impute missing values where applicable and encode categorical fields using the saved pipeline.

03Classify

The trained Random Forest returns a stage label and class probability estimates.

04Review

View the result, inspect model evaluation, and optionally save/export demo records.

Scope and medical disclaimer

This is an educational prototype, not a clinically validated product or medical device. Dataset provenance, labels, units, representativeness, and licensing must be verified. Stage labels reflect the supplied dataset; do not treat predictions as a diagnosis or use them to make treatment decisions. The app does not include authentication and must not be used with identifiable patient data.
