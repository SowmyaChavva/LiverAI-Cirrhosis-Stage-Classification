# LiverAI – Machine Learning-Based Liver Cirrhosis Stage Classification

LiverAI is an academic machine learning project that explores multiclass classification of liver cirrhosis stages using clinical data. It combines a Python-based machine learning pipeline with a Flask web application and an interactive dashboard for submitting inputs, viewing predictions, and reviewing model evaluation results.

> **Disclaimer:** This project is developed for educational and research purposes only. Its predictions may be inaccurate and must not be used for medical diagnosis, treatment, or clinical decision-making. The model has not been clinically validated. Consult a qualified healthcare professional for medical advice.

## Overview

LiverAI demonstrates how machine learning can be integrated into a web application to classify clinical records into three dataset-defined classes: Stage 1, Stage 2, and Stage 3.

The project focuses on the complete workflow, including data preprocessing, model training, evaluation, web integration, and presentation of results through a dashboard.

## Objectives

* Build a multiclass machine learning classification pipeline.
* Preprocess numerical and categorical clinical features.
* Integrate the trained model into a Flask web application.
* Display predicted classes and model probability estimates.
* Present model evaluation metrics to support technical analysis.
* Demonstrate responsible documentation of dataset limitations and model performance.

## Features

* **Interactive dashboard:** A central page for navigating the application and viewing available project statistics.
* **Stage classification:** Predicts one of three classes using the trained machine learning pipeline.
* **Prediction results:** Displays the predicted class and model-generated probabilities when available.
* **Prediction history:** Provides access to previously saved predictions if the history feature is enabled.
* **Model evaluation:** Displays evaluation metrics and classification results when generated by the training process.
* **Data preprocessing:** Handles missing values and encodes categorical variables through a machine learning pipeline.
* **Project documentation:** Explains the workflow, technologies, limitations, and intended educational use.

## Technology Stack

* **Language:** Python
* **Web framework:** Flask
* **Machine learning:** Scikit-learn
* **Data processing:** Pandas and NumPy
* **Model persistence:** Joblib
* **Frontend:** HTML and CSS
* **Database:** SQLite, if enabled in the included application

## Machine Learning Workflow

1. Load the clinical dataset.
2. Inspect the data and remove exact duplicate records.
3. Separate input features from the target stage.
4. Split the data into training and testing sets using stratification.
5. Impute missing numerical and categorical values.
6. Encode categorical features.
7. Train a Random Forest classifier.
8. Evaluate the model using held-out test data.
9. Save the trained pipeline and evaluation metrics.
10. Load the model in Flask and display predictions through the web interface.

## Input Features

The model uses a combination of clinical and demographic features, including age, follow-up duration, bilirubin, cholesterol, albumin, copper, alkaline phosphatase, SGOT, triglycerides, platelets, prothrombin, and selected categorical variables.

The exact feature names and accepted values are defined by the dataset and application form.

## Installation and Setup

### Prerequisites

* Python 3.10 or a compatible Python version
* pip
* Git (for version control)

### 1. Clone the repository

```bash
git clone https://github.com/SowmyaChavva/LiverAI-Cirrhosis-Stage-Classification.git
cd LiverAI-Cirrhosis-Stage-Classification
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Create a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
```

### 3. Install dependencies

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. Train the model

```powershell
.\.venv\Scripts\python.exe train_model.py
```

This step should generate the trained model and evaluation output required by the application.

### 5. Start the Flask application

```powershell
.\.venv\Scripts\python.exe app.py
```

Open the local address displayed in the terminal, typically:

`http://127.0.0.1:5000`

## Dataset and Limitations

The application uses a clinical dataset containing stage labels. Before sharing the dataset publicly, verify its original source, usage permissions, and license.

The dataset used during development contains substantial exact duplication. Duplicate handling and evaluation methodology should therefore be reviewed carefully to reduce the risk of misleading performance estimates.

Other limitations include:

* The model is not clinically validated.
* Dataset labels may not represent every patient's clinical condition.
* Model probabilities are not necessarily calibrated estimates of clinical risk.
* Performance on new or independently collected data may differ from test-set performance.
